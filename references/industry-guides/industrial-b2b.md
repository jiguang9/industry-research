# 行业检索方法：工业与 B2B 类

适用于制造、工业设备、工业软件、供应链/物流、建筑与工程服务等采购方与使用方通常是企业、决策链条较长的行业。本文件只提供方法、术语和查证思路，不固化具体的市场规模或增速数字（这类数字会过期，应在每次研究时重新查证并注明时期）。

## 常见容易混淆的口径

- **产值 / 销售额 / 出货量**：制造类行业常见三种统计口径混用，务必确认统计对象是"生产了多少"还是"卖出去了多少"还是"实物数量"。
- **软件许可 / 订阅 / 实施服务**：工业软件收入常拆分为许可费、订阅费（SaaS 化后）、实施与运维服务费，三者增长趋势可能完全不同。
- **设备保有量 / 新增销量**：存量市场和增量市场的驱动因素不同，报告设备行业时要分开讨论。
- **直销 / 渠道分销 / 系统集成商代理**：同一产品通过不同渠道流转时，终端价格和毛利结构会有明显差异。

## 采购与决策链

工业 B2B 采购通常涉及使用部门（提出需求）、采购部门（走流程、比价）、技术/质量部门（把关规格）、财务/管理层（最终审批）等多个角色，决策周期可能是几周到一两年。研究时应尝试回答：

- 谁发起采购需求？谁最终签字？
- 是否需要招投标、资质审核、样品认证？
- 复购/续约的驱动因素是什么（设备寿命周期、合同到期、政策要求）？

## 查证线索

- 政府采购网、招投标平台的公开中标公告，可用于交叉验证某类采购的价格区间和主要供应商。
- 行业协会/标准化组织发布的技术标准和分类说明，用于确认细分边界。
- 上市公司年报中的"主要产品及用途""主要客户"部分，比营销通稿更能反映真实业务结构。
- 展会/行业媒体的参展企业名单，可作为寻找细分领域代表企业的线索（本身不能作为规模或排名依据）。

## 常见分析误区

- 把"设备保有量大"直接等同于"存在巨大的替换/服务市场"，忽略设备寿命、维护习惯、预算周期等约束。
- 把上市公司的财务表现当作整个细分行业的代表，忽视大量非上市中小企业的存在。
- 忽略工业品行业中常见的定制化程度差异，用消费品行业的"标准化产品+统一定价"思路分析工业品。
