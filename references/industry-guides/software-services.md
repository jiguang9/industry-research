# 行业检索方法：软件与服务类

适用于 SaaS、企业服务、IT 咨询、云计算、平台型服务等以订阅、项目制或按使用量收费为主的行业。本文件只提供方法、术语和查证思路，不固化具体的市场规模或增速数字。

## 常见容易混淆的口径

- **ARR / MRR / 总营收**：年度经常性收入（ARR）、月度经常性收入（MRR）常被与包含一次性实施费、硬件转售的总营收混用，须分开陈述。
- **注册用户数 / 付费用户数 / 活跃用户数（MAU/DAU）**：三者差异巨大，报告增长时要明确指的是哪一种。
- **客单价（ACV）/ 续费率（NRR）/ 流失率（Churn）**：这些是判断商业模式健康度的关键指标，缺失时不要用"增长快"笼统代替。
- **软件收入 / 平台交易额（GMV）**：平台型服务常把交易撮合总额和平台自身实际收入混着报道，须分清。

## 商业模式与渠道

- 收费模式：订阅制（按席位/按用量/分层套餐）、项目制（实施+运维）、交易抽成、广告/流量变现，不同模式的成本结构和现金流特征不同。
- 获客路径：自助注册（PLG，产品驱动增长）、销售驱动（SLG，需要销售团队和较长的销售周期）、渠道代理商，三者的销售周期和获客成本差异很大。
- 续约与扩张：企业服务的关键往往不是首次成交，而是续约率和账户内扩张（更多席位/更高套餐），研究时应尝试找到相关线索。

## 查证线索

- 上市/拟上市 SaaS 公司的招股书、年报中通常会披露 ARR、NRR、客户集中度等指标，是了解行业健康度基准的一手来源。
- 产品官网的定价页和服务条款，可用于理解实际的收费结构，不能仅凭"定价页上写的最低价"判断整体客单价。
- 招聘网站上目标客户企业的相关职位描述，有时能反映该企业实际使用的工具和技术栈线索（谨慎使用，仅作辅助线索）。
- 开发者社区、行业论坛中的真实使用反馈，可作为渠道和产品体验的补充信息来源。

## 常见分析误区

- 把融资金额当作市场规模或商业化成功的证据，融资只反映投资人预期，不直接等于收入或盈利。
- 忽略企业服务中"合同价"与"实际到账收入"之间可能存在的分期、折扣、退款差异。
- 把海外同类产品的商业模式和定价直接套用到国内市场，忽略采购习惯、付费意愿、竞争格局的差异。
