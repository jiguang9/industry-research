# 协作机器人（中国）竞品研究交接 Brief

- 行业范围：协作机器人整机制造（与 report.md 一致）
- 市场地区：全球出货量排名口径为全球；企业经营状况以中国厂商为主
- 研究目的：示例——如果用户希望进一步比较越疆、遨博、节卡、艾利特这几家中国厂商的定价、产品线和渠道策略差异，可将此文件交给竞品分析工具继续
- 来源报告：report.md（本目录，研究日期 2026-09-03）

## 候选企业与入选理由

| 企业 | 入选理由 | 相关证据 ID |
|---|---|---|
| 越疆 | 2023年出货量口径下中国厂商中排名最高（全球第二），且已完成港股上市，资本市场信息相对透明 | C005, C008 |
| 节卡机器人 | 2023年出货量全球第五，是本次研究中财务数据最完整的企业（因IPO审核披露），且有IPO终止这一明确近期事件 | C001, C002, C003, C004 |
| 遨博智能 | 2023年出货量全球第三，中国厂商中的另一家头部企业 | C005 |
| 艾利特机器人 | 公开资料显示海外销售占比较高（47%），但本次未查证到财务和上市状态信息，适合作为需要补充研究的对象 | C009 |

## 现有证据摘要

- 越疆：2023年全球出货量1.6万台，全球份额13%，2024年12月港交所上市（C005、C008，来源见 evidence.json 的 S003）。
- 节卡：2020-2022销量与营收增长轨迹、2022-2025H1盈亏变化、2025年12月IPO终止（C001-C004，来源 S001、S002）。
- 遨博：仅有2023年全球出货量排名第三这一条信息（C005，来源 S003），无财务数据。
- 艾利特：仅有百科/展会资料中的销售台数和海外占比，上市状态未查证（C009）。

## 待比较的具体问题

1. 越疆、遨博、节卡、艾利特在负载范围、应用场景定位上的产品线差异。
2. 各企业的渠道策略差异（直销 vs 集成商代理 vs 海外经销）。
3. 已上市（越疆）与未上市（节卡、其他）企业在披露信息完整度上的差异，如何影响可获得的比较维度。
4. 除节卡外，其他企业是否有可查证的盈利能力数据，用于验证 report.md 中"行业整体尚未形成稳定盈利模式"这一判断（目前仅有节卡一家样本，见 report.md 证据缺口 G001）。
